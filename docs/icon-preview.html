icon & splash

One mark, three surfaces

A monospace-drawn K — three strokes, one weight, square terminals — built to sit on the app's existing dark-bg / single-mint-accent language rather than invent a new one. It composites straight from three line segments, so it is one adaptive-icon foreground and one splash icon, not a set of exported pngs.

Launcher — mask shapes

circle (Pixel)
squircle (Samsung)
rounded square

Safe zone

Every stroke terminal sits at radius ≈32.1dp from centre — just inside the 33dp safe-zone circle adaptive icons guarantee across every launcher mask, so the mark holds its proportions whether the shape is a circle, a squircle, or a rounded square. Nothing depends on corner bleed.

Splash

Same drawable, same background colour, drawn full-bleed with androidx.core.splashscreen so API 26+ gets the same reveal API 31 draws natively. It hands off to Theme.KiroForAndroid the moment Compose's first frame is up — no separate splash artwork to keep in sync, no second place the mark can drift out of date.
